# Flappy Bird - Projeto p5.js

## Descrição

Este projeto consiste em um jogo inspirado no clássico Flappy Bird, desenvolvido utilizando JavaScript e a biblioteca p5.js.

O objetivo do jogo é controlar o pássaro e desviar dos canos, acumulando pontos a cada obstáculo ultrapassado.

---

## Como jogar

* Clique com o mouse ou pressione a tecla ESPAÇO para fazer o pássaro pular
* Desvie dos canos
* Cada cano ultrapassado adiciona 1 ponto
* O jogo termina ao colidir com um cano ou sair da tela

---

## Como executar

1. Acesse o editor do p5.js:
   https://editor.p5js.org/

2. Crie um novo projeto

3. Copie e cole o código do jogo

4. Clique em Run

---
## Estrutura do jogo

* Tela inicial: apresenta instruções ao jogador
* Jogo: execução principal com movimento e obstáculos
* Game Over: exibe pontuação final e permite reinício

---

## Pontuação

* A pontuação aumenta conforme o jogador ultrapassa os obstáculos
* O valor é exibido na tela durante o jogo
